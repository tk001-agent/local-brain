# Mywiny

这是一个本地档案管理员系统：承接大量零散对话，自动按话题多层级归类，并提炼出对每个话题的理解。它为解决 agent 丢失记忆的问题而生——新的 agent 接入后，能快速了解所有话题、直接上岗。

## 核心架构

```
外部输入 → 网关 → 规则分类 → 双写存储 → 即时分析 → 话题/理解文档
```

### 模块

| 模块 | 职责 |
|------|------|
| `gateway` | API 服务入口，数据接入，规则分类，Markdown 归档 |
| `analyzer` | LLM 分析引擎，话题提取，理解文档生成 |
| `db` | SQLite 结构化存储，对话记录与话题关系 |
| `config` | 配置中心，阈值控制，保留策略 |
| `scheduler` | 定时调度兜底 |
| `evolver` | 话题进化与归并 |

### 数据流

1. **接入** — 通过 API 推送对话数据
2. **分类** — 规则分类器即时判断消息类型、紧急度、情绪
3. **双写** — SQLite 存结构化数据，Markdown 存可读档案
4. **分析** — 即时触发 LLM 提取话题、生成理解文档
5. **沉淀** — 话题层级自动归并，历史版本可追溯

## 存储

- **SQLite** — 对话记录、话题关系、元数据
- **Markdown** — 话题文档、理解文档，人类可读
- 按日期组织目录，支持版本保留和自动归档

## 技术选型

- **语言**：Python
- **Web 框架**：Flask
- **数据库**：SQLite
- **LLM 接入**：兼容 OpenAI 接口的 API 服务
- **部署**：单机轻量，适配 4核4G 配置
